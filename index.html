E-Commerce Analytics

Modern Data Warehouse

A batch data warehouse for Olist Brazilian E-Commerce built with DuckDB and dbt, featuring a Kimball star schema, SCD Type 2 snapshots, incremental modeling, and 60+ automated data quality tests.

Open Dashboard View on GitHub

The Challenge

E-commerce platforms store raw operational data across highly normalized, loosely structured tables. Running analytics directly on transactional data stalls applications, creates inconsistent metric definitions, and lacks historical accuracy.

The Solution

A Kimball star-schema data warehouse that transforms raw Olist CSVs into clean, audited analytical tables — enabling fast reporting, accurate point-in-time analysis, and automated data quality enforcement.

  • • SCD Type 2 tracking for customer geography changes
  • • Incremental fact table with 3-day lookback for late data
  • • 28 data quality tests (unique, not_null, relationships)
  • • Zero-cloud, local-first architecture (S3-ready as it scales)
